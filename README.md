# AI Travel Analytics Dashboard

An AI-powered Travel Analytics Dashboard built using Streamlit, Pandas, and Plotly.  
This project provides interactive travel insights, travel analysis charts, AI travel finder, dynamic maps, and user authentication features.

---

## 🚀 Features

- User Login & Registration System
- Interactive Travel Analytics Dashboard
- AI Travel Finder
- Dynamic Google Map Integration
- Advanced Charts using Plotly
- Travel Assistant
- Dataset Filtering & Search
- Modern Glassmorphism UI Design

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Regex
- HTML/CSS
- Streamlit Option Menu

---

## 📊 Dashboard Modules

### 📂 Dataset
- View dataset
- Search & filter data
- Download filtered CSV

### 🌍 Place Explorer
- Country & city analytics
- Tour statistics
- KPI metrics

### 📈 Travel Analysis
- Country-wise trips
- Budget analysis
- Rating analysis
- Travel trends
- Treemap & Map charts

### 🗺️ Map View
- Dynamic Google Maps integration

### 🤖 AI Travel Finder
- Smart travel recommendation system

### 💬 Travel Assistant
- Ask questions about travel dataset
